HOW TO PREVIEW
1. Extract the ZIP file.
2. Open any project folder.
3. Double-click index.html to preview in your browser.
4. Keep each project's style.css and script.js (where present) in the same folder.

IMPORTANT
These are practice/demo projects, not paid client work. Update any text or details you need.
The main portfolio links to the demo folders using relative links; those links work locally.
If you publish each folder separately, update the project links on the main portfolio to the published URLs.

HOW TO PUBLISH A PROJECT WITH GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository for a demo (e.g. saas-landing-demo).
2. Open the repository and choose Add file > Upload files.
3. Upload the contents of the project folder, not the parent folder. Ensure index.html is at repository root.
4. Commit the files.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
7. Wait a few minutes and open the published link shown in Settings > Pages.
8. Repeat for each demo project.
Never upload passwords, API keys, private client data, or other secrets to a public repository.
